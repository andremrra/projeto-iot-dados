\begin{abstract}
\noindent
Este trabalho apresenta o desenvolvimento de uma plataforma completa de integração de dados
para monitoramento industrial baseada em Internet das Coisas (IoT). A solução implementa
a arquitetura \textit{Medallion Lakehouse} com três camadas de dados (Bronze, Silver e Gold)
armazenadas no MinIO, um sistema de armazenamento de objetos compatível com S3. A ingestão
de dados em tempo real é realizada via Apache Kafka, o processamento batch utiliza Apache Spark,
a orquestração de pipelines é feita pelo Apache Airflow e a detecção de anomalias em
\textit{streaming} emprega o Spark Structured Streaming com janelas temporais de cinco minutos.
Adicionalmente, integra-se a fontes heterogêneas como sistemas ERP (PostgreSQL),
APIs REST de manutenção e cadastro de equipamentos no MongoDB. Os resultados demonstram
um pipeline funcional capaz de processar mais de 100 eventos por segundo, com latência
de alerta inferior a dois minutos.
\\\textbf{\keyword{Palavras-chave: }} IoT. Data Lakehouse. Apache Kafka. Apache Spark. Airflow. Integração de Dados.
\end{abstract}

\begin{abstract}
\noindent
This work presents the development of a complete data integration platform for industrial
monitoring based on the Internet of Things (IoT). The solution implements the Medallion
Lakehouse architecture with three data layers (Bronze, Silver, and Gold) stored in MinIO,
an S3-compatible object storage system. Real-time data ingestion is performed via Apache Kafka,
batch processing uses Apache Spark, pipeline orchestration is handled by Apache Airflow,
and streaming anomaly detection employs Spark Structured Streaming with five-minute time
windows. Additionally, it integrates heterogeneous sources such as ERP systems (PostgreSQL),
REST maintenance APIs, and equipment registration in MongoDB. Results demonstrate a
functional pipeline capable of processing over 100 events per second, with alert
latency under two minutes.
\\\textbf{\keyword{Keywords: }} IoT. Data Lakehouse. Apache Kafka. Apache Spark. Airflow. Data Integration.
\end{abstract}
